What it does
01

New submissions

Detects newly visible accepted submissions on the monitored public profile.

02

Progress changes

Detects changes in Easy, Medium and Hard solved counts.

03

Ranking changes

Detects changes to the user's public LeetCode ranking.

04

Desktop notifications

Sends native Windows notifications when activity is detected.

05

Tiny memory footprint

Uses requests and a small JSON state file. No browser automation required.

06

No account required

The script monitors publicly accessible profile information without storing credentials.

How detection works

The first execution creates a small leetcode_state.json file containing a snapshot of the publicly visible data. Every subsequent check compares the new snapshot against that previous state.

The script therefore doesn't need a database or a large in-memory history. It remembers only what is necessary to detect changes.

Up and running in under a minute.

Installation

Clone the repository

git clone https://github.com/HanshalBobate/leetcode-stalker.git

Install dependencies

pip install requests winotify

Configure the username

Open stalker.py and change USERNAME to the public LeetCode username you want to monitor.

Start the watcher

python stalker.py

Know the limits.

Important

This monitors public information only.

The project does not log into another person's account, bypass authentication, access private submissions, or attempt to circumvent LeetCode protections.

The recent-submission information available through the public interface is limited, so this should be treated as a lightweight activity monitor rather than a complete historical archive.

Use a reasonable polling interval. The default is 60 seconds.
